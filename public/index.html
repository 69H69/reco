Set up Google Drive

Google requires every app to use its own “key” to write to a Drive. You create yours once, for free, in about 5 minutes. Reco only sees the videos it uploads, never the rest of your Drive.

  1. Create a project named “Reco” (sign in with your Google account).Open
  2. Enable the Google Drive API: click “Enable”.Open
  3. Consent screen: “Get started”, app name “Reco”, your email, audience “External”. Then, under “Audience”, click Publish app (otherwise the sign-in expires after 7 days).Open
  4. Create an OAuth client of type “Desktop app”, named “Reco”, then click Download JSON.Open
  5. Import the file you downloaded (it's called “client_secret_… .json”).

My Reco server

For the full Tella experience (share page, views, online library), publish your videos to your own Cloudflare server. You create it once with the project's “Deploy to Cloudflare” button (free up to 10 GB; Cloudflare asks for a card to enable R2 storage).
