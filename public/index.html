Configurer Google Drive

Google exige que chaque appli ait sa propre « clé » pour écrire dans un Drive. Tu la crées une seule fois, gratuitement, en 5 minutes environ. Reco ne verra que les vidéos qu'il envoie, jamais le reste de ton Drive.

  1. Crée un projet nommé « Reco » (connecte-toi avec ton compte Google).Ouvrir
  2. Active l'API Google Drive : bouton « Activer ».Ouvrir
  3. Écran de consentement : « Commencer », nom « Reco », ton e-mail, public « Externe ». Ensuite, dans « Audience », clique Publier l'application (sinon la connexion expire au bout de 7 jours).Ouvrir
  4. Crée un client OAuth de type « Application de bureau », nom « Reco », puis clique Télécharger le JSON.Ouvrir
  5. Importe le fichier téléchargé (il s'appelle « client_secret_… .json »).

Mon serveur Reco

Pour avoir tout comme Tella (page de partage, vues, bibliothèque en ligne), publie tes vidéos sur ton propre serveur Cloudflare. Tu le crées une fois avec le bouton « Deploy to Cloudflare » du projet (gratuit jusqu'à 10 Go ; Cloudflare demande une carte pour activer le stockage R2).
